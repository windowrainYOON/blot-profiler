# Blot Profiler

웨스턴 블롯 TIF 이미지에서 밴드를 자동으로 찾아 intensity를 정량하고, internal control(loading control)로
정규화한 뒤 그래프까지 그려주는 macOS용 GUI 프로그램입니다. Python(PySide6 + NumPy/SciPy/scikit-image/matplotlib)으로 만들었습니다.

## 주요 기능

- **TIF 입력**: 8/16/32-bit 그레이스케일·RGB TIF (PNG/JPG도 가능). 어두운 밴드/밝은 배경(ECL·필름)은 자동 반전.
- **미리보기**: 입력 이미지의 극성과 관계없이 흰 배경 + 검은 밴드로 표시합니다.
- **밴드 자동 검출**: 노이즈 기반 임계값 → 붙어 있는 밴드는 레인 간격으로 분리 → 가로줄(행)과 레인으로 자동 정리.
  밴드가 없는 레인(예: DMSO 레인의 Kras)에도 같은 위치에 박스를 만들어 0에 가까운 값으로 정량합니다.
- **그룹 = 이름**: 밴드를 드래그로 선택하고 우클릭해서 그룹을 만들면, 그 이름이 곧 단백질 이름이나 레인 이름이 됩니다.
  - *새 단백질(행) 그룹 만들기*: 예) Vinculin, pErk. 한 단백질 그룹의 박스는 모두 같은 크기이고, 같은 레인 안의 밴드는 합해서 정량합니다(이중 밴드 합치기).
  - *새 레인(열) 그룹 만들기*: 예) DMSO, IgG 12h. 같은 단백질의 밴드를 여러 열에서 고르면 그 열들이 한 레인 그룹의 반복이 되고, 그래프에서 평균 ± SD로 나옵니다.
  - **밴드 ID**는 `단백질_레인`으로 자동으로 붙습니다(예: `Kras_IgG_12h`). 이름이 겹치면 `_2`, `_3`이 붙습니다.
- **드래그로 박스 크기 조절**: 우클릭 → *박스 크기 조절 모드*에서 박스 가장자리나 모서리를 끌면, 같은 단백질 그룹 전체와 함께 선택한 밴드의 행이 같이 바뀝니다. Esc로 끝냅니다.
- **배경(background noise) 제거** 4가지: 없음 / Rolling ball(이미지 전체) / 박스 위·아래 로컬 배경 / 행 내 레인 사이 배경.
- **Target / Control 지정**: 단백질마다 측정(Target), Control(Loading), 제외 중에서 고릅니다.
  Target ÷ Control을 레인별로 계산하고 기준 레인을 1로 정규화합니다.
- **수식 만들기**: *수식 추가…*를 누르면 수식 창이 열립니다. 단백질 그룹·밴드 ID·이미지별 항목·큰 그룹은 드롭다운에서 골라 *넣기*로 넣고,
  직접 입력하는 것은 `+ − × ÷ ( )`와 숫자뿐입니다(키보드나 버튼). 미리보기로 결과를 바로 확인하고, 수식을 더블클릭하면 다시 편집합니다.
  예) `pErk / Erk`, `Kras_DOX / Kras_DMSO`.
- **밴드 ROI·그룹 저장/불러오기**: 박스 위치·크기, 단백질/레인 그룹 이름과 역할만 따로 `_roi.json`으로 저장하고, 다른 이미지에 적용할 수 있습니다
  (*1. 검출* 탭 또는 *파일* 메뉴). 이미지 크기가 다르면 비율대로 맞출지 묻습니다.
- **여러 이미지 (5번 탭)**: TIF를 여러 개 열고(이미지 탭 I1, I2 …) 이미지들의 그룹을 체크해 *큰 그룹*을 만듭니다.
  - *레인 큰 그룹*: 이미지마다 이름이 다른 레인을 하나로 맞춥니다. 예) I1의 'IgG 12h'와 I2의 'IgG12'.
  - *단백질 큰 그룹*: 여러 블롯의 단백질 값을 레인별로 평균 ± SD 냅니다. 이미지마다 기준 레인을 1로 맞춘 뒤 평균합니다.
  - *이미지 간 수식*: 수식 창에서 I1·I2 …의 단백질/밴드와 큰 그룹을 골라 만듭니다. 예) `I2.Kras / I1.Kras`.
    이미지 사이의 레인은 레인 이름(또는 레인 큰 그룹)으로 맞춰집니다.
- **그래프**: 4:3 비율로 창 너비에 맞춰 늘어납니다.
- **내보내기**: 밴드별 raw/배경/net 값, 이미지별 결과, 여러 이미지 결과를 담은 CSV. 그래프는 PNG/PDF/SVG, 박스가 표시된 이미지도 저장할 수 있습니다. 분석 파일(.json)은 다시 열어 고칠 수 있고, 예전 버전 파일도 열립니다.

## 사용 순서

1. **1. 검출** 탭에서 TIF를 엽니다(창에 끌어다 놓아도 되고, 여러 개도 됩니다). 밴드를 자동으로 찾습니다.
2. 이미지에서 밴드를 드래그로 선택하고 우클릭해서 **단백질 그룹**과 **레인 그룹**을 만듭니다.
   더블클릭: 밴드 추가 / Delete: 삭제 / 방향키: 1px 이동(Shift: 5px) / ⌘(Ctrl)+휠: 확대·축소
3. **2. 단백질 / 레인** 탭에서 역할(Target / Control)과 박스 크기를 정합니다.
4. **3. 밴드** 탭에서 밴드별 정량값과 프로파일을 확인합니다.
5. **4. 정량 / 그래프** 탭에서 현재 이미지의 기준 레인과 수식을 정합니다.
6. 이미지가 여러 개면 **5. 여러 이미지** 탭에서 큰 그룹과 이미지 간 수식을 만듭니다.

### 정량 방식

- 정량값(Net) = 박스 안 픽셀 intensity 합(integrated density) − 배경.
- Rolling ball은 이미지 전체에서 부드러운 배경을 추정해 뺍니다 (반지름은 밴드 높이의 3~5배 이상 권장).
- 로컬 배경은 박스 바로 위·아래 띠의 중앙값을, 행 배경은 같은 행에서 박스 사이(레인 사이) 픽셀의 중앙값을 픽셀당 배경으로 뺍니다.
- 가장 정확한 결과를 위해 이미저에서 내보낸 **원본 16-bit TIF**를 쓰고, 포화(saturation)된 밴드는 피하세요.
  스크린샷·JPEG는 대비 조정과 압축 때문에 값이 왜곡될 수 있습니다.

## 설치 (macOS)

### .dmg로 설치

`BlotProfiler-<버전>.dmg`를 열고 **Blot Profiler.app**을 Applications 폴더로 끌어 놓으세요.
서명되지 않은 앱이라 처음 실행 시 경고가 나오면 Finder에서 앱을 우클릭 → *열기*를 누르세요.

### 직접 빌드

```bash
git clone https://github.com/windowrainYOON/blot-profiler.git
cd blot-profiler
./build_mac.sh            # dist/BlotProfiler-<버전>.dmg 생성
./build_mac.sh --install  # 빌드 후 /Applications 에 설치까지
```

Python 3.10 이상이 필요합니다 (`PYTHON=/path/to/python3 ./build_mac.sh` 로 지정 가능).

### 소스에서 바로 실행

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python run_blot_profiler.py [이미지.tif]
```

## 개발

```bash
pip install -r requirements.txt pytest
python -m pytest tests
```

- `blot_profiler/core.py`: 이미지 로딩, 배경 제거, 밴드 검출, 정량, 수식 계산 (GUI와 독립)
- `blot_profiler/gui.py`: PySide6 GUI
- `packaging/`: PyInstaller 설정과 아이콘
- `tests/data/example_blot*.tif`: 예시 블롯 (스크린샷에서 잘라낸 저해상도 이미지, 테스트용)
