# Blot Profiler

웨스턴 블롯 TIF 이미지에서 밴드를 자동으로 찾아 intensity를 정량하고, internal control(loading control)로
정규화한 뒤 그래프까지 그려주는 macOS용 GUI 프로그램입니다. Python(PySide6 + NumPy/SciPy/scikit-image/matplotlib)으로 만들었습니다.

## 주요 기능

- **TIF 입력**: 8/16/32-bit 그레이스케일·RGB TIF (PNG/JPG도 가능). 어두운 밴드/밝은 배경(ECL·필름)은 자동 반전.
- **미리보기**: 입력 이미지의 극성과 관계없이 흰 배경 + 검은 밴드로 표시합니다.
- **밴드 검출: 레인 먼저 찾기** (기본, 1번 탭 '검출 방식'; Western·DNA gel 모두). 레인을 먼저 찾고(밴드 위·아래 가장자리의 세로 변화로 레인 간격을 재고
  레인 줄을 맞춤), 레인마다 밴드를 찾은 뒤, 같은 높이의 밴드를 줄로 묶습니다. 레인은 ±10°까지 기울어질 수 있고, 같은 레인 안에서 밴드가 좌우로
  레인 간격의 10% 정도 어긋나도 잡히도록 레인 영역을 잡습니다(레인 중심선은 점선으로 표시, '레인 선'으로 끄기).
  - 직접 옮기거나 추가한 박스는 다시 검출해도 그대로 남습니다.
  - **기울기 자동 보정**: 밴드 줄이 0.3° 이상 기울어 있으면 이미지 전체를 돌려(마커 이미지도 같은 각도로) 맞추고 다시 검출합니다. 1번 탭 '미세' 회전에 각도가 보이고 거기서 되돌릴 수 있습니다(옵션으로 끄기 가능).
  - 이전 방식은 '이전 검출 방식'으로 고를 수 있습니다.
- **실험 종류: Western blot / DNA gel 전기영동** (1번 탭, 이미지마다, 프로젝트에 저장). 이미지를 열 때 자동으로 정합니다:
  짝이 되는 마커 파일이 있으면 Western, 이미지 안에 ladder 레인(밴드가 많은 레인)이 보이면 DNA gel, 애매하면 Western. 언제든 바꿀 수 있습니다.
  - DNA gel 모드: 레인별로 밴드를 찾고(겔·트레이 가장자리, well, 얼룩은 걸러냄), ladder 레인은 'Ladder' 그룹(정량 제외)으로 묶어 M, M2로 표시합니다.
    밴드를 선택해 우클릭 → 'ladder로 지정/빼기'로 고칩니다. ladder 밴드 높이는 Figure의 크기 눈금(bp)이 되고, '1 kb / 1 kb Plus / 100 bp / 50 bp'
    ladder 값을 위에서부터 한 번에 채울 수 있습니다. 정량은 그대로 됩니다(Control이 없으면 레인별 Net).
  - JPG/PNG 사진도 열립니다(컬러는 회색으로 바꿔 정량).
- **이미지 방향·자르기** (1번 탭): ⟲90°/⟳90°/180°, 미세 회전(0.1° 단위), '선으로 수평 맞추기'(well이나 밴드를 따라 선을 그으면 수평으로 돌림),
  '자르기 영역 그리기'(트레이·배경 잘라내기), '겔 영역 자동 찾기'(겔 사진을 열면 겔 부분만 자동으로 자르기 — 옵션, '자르기 해제'로 되돌림), 원본으로. 바꾸면 밴드를 다시 검출하고, 마커에도 같은 회전·자르기가 적용되며, 프로젝트에 저장됩니다.
  정량은 회전/자른 이미지의 raw 값으로 합니다(90° 단위는 그대로, 미세 회전은 선형 보간).
- **마커(ladder) 이미지 같이 받기**: 블롯 TIF를 열고 밴드를 검출하면 '2단계: 마커 이미지 추가' 창이 뜹니다.
  어떤 이미지를 넣어야 하는지(같은 막을 같은 자리에서 찍은 marker/white-light 사진. 크기가 달라도 가로세로 비율이 5% 이내로 비슷하면 블롯 크기에 맞춰 불러옵니다) 설명과 함께 블롯 미리보기,
  '마커 이미지 추가하기' 버튼, 자동으로 찾은 후보(같은 폴더의 '…Marker…' 파일), 크기 확인, '건너뛰기'가 있습니다.
  블롯과 함께 고르거나 끌어다 놓은 마커는 바로 붙습니다.
- **마커 방향 맞추기**: 마커 사진이 블롯과 가로·세로가 바뀌어 저장된 경우(예: 블롯 1408×1024, 마커 1024×1408) 자동으로 90° 돌려 맞춥니다(옵션).
  90°와 270° 중 어느 쪽이 맞는지는 화학발광 이미지와 일반 사진을 비교해서는 확실히 알 수 없어서, '2단계' 창에 맞는 방향 후보(90° 반시계/시계, 좌우 반전)를
  미리보기로 보여 주고 한 번에 고르게 합니다. 나중에는 1번 탭 '마커 방향'에서 바꿀 수 있고, 프로젝트에 저장됩니다.
- **마커 띠 영역 직접 정하기**: 마커 위의 파란 상자(메인 화면의 마커, Figure 탭 '마커 참고')를 끌어서 옮기고(위아래 = 세로 위치 보정),
  가장자리로 폭을 바꿉니다. '마커 참고'에서 '드래그 = 마커 띠 영역 새로 그리기'를 고르면 새로 그릴 수 있고, '자동으로 찾기'로 다시 찾습니다.
  이름에 'marker'가 들어간 파일만 끌어다 놓으면 지금 이미지의 마커로 들어갑니다. 1번 탭에서 다시 열거나 뺄 수 있습니다.
  밴드를 잡는 화면에서도 마커가 블롯 왼쪽에 같은 높이로 보입니다('마커 같이 보기'). Figure 탭도 같은 마커를 씁니다.
- **밴드 자동 검출**: 노이즈 기반 임계값 → 붙어 있는 밴드는 레인 간격으로 분리 → 가로줄(행)과 레인으로 자동 정리.
  밴드가 없는 레인(예: DMSO 레인의 Kras)에도 같은 위치에 박스를 만들어 0에 가까운 값으로 정량합니다.
  검출은 대비를 조정한(LUT: 퍼센타일 스트레치 + 감마 0.6) 작업용 사본에서 해서 흐린 밴드(예: Vinculin)도 잡습니다. 이 사본은 검출에만 씁니다.
- **raw intensity 정량**: 정량은 항상 원본 TIF의 raw 픽셀값으로 합니다. 화면 대비와 검출용 LUT는 쓰지 않고,
  어두운 밴드 이미지는 선형 반전(최댓값 − 값)만, 그리고 선택한 배경 제거만 적용합니다.
- **레인 자동 지정**: 박스 위치나 크기를 바꿀 때마다(드래그 중, 방향키, 크기 입력 포함) 박스 위치를 왼쪽부터 순서대로 보고 레인(L1, L2 …)을 다시 잡습니다.
  이름을 붙인 레인 그룹은 그대로 유지되고, 레인은 언제든 *새 레인(열) 그룹 만들기*로 고칠 수 있습니다(2번 탭에서 끌 수도 있음).
- **그룹 = 이름**: 밴드를 드래그로 선택하고 우클릭해서 그룹을 만들면, 그 이름이 곧 단백질 이름이나 레인 이름이 됩니다.
  - *새 단백질(행) 그룹 만들기*: 예) Vinculin, pErk. 한 단백질 그룹의 박스는 모두 같은 크기이고, 같은 레인 안의 밴드는 합해서 정량합니다(이중 밴드 합치기).
  - *새 레인(열) 그룹 만들기*: 예) DMSO, IgG 12h. 같은 단백질의 밴드를 여러 열에서 고르면 그 열들이 한 레인 그룹의 반복이 되고, 그래프에서 평균 ± SD로 나옵니다.
  - **밴드 ID**는 `단백질_레인`으로 자동으로 붙습니다(예: `Kras_IgG_12h`). 이름이 겹치면 `_2`, `_3`이 붙습니다.
- **마우스로 박스 고치기**: 클릭·드래그 = 선택(여러 개), 박스를 잡고 끌기 = 이동, Backspace = 삭제, 우클릭 = 그룹 설정(단백질/레인 그룹·역할)·병합,
  박스 더블클릭 = 크기 수정(가장자리·모서리를 끌면 같은 단백질 행이 함께 바뀜, Esc나 빈 곳 클릭으로 끝), 빈 곳 더블클릭 = 박스 추가.
  **떨어진 밴드를 하나의 레인으로**: 단백질마다 하나씩 박스를 고르고(Shift/⌘-클릭 또는 드래그) 우클릭 → 그룹 설정 → '레인(열) 그룹으로 묶기'.
  위치가 멀리 떨어져 있어도 고른 박스만으로 한 레인이 되고(◆ 표시와 주황 점선, 레인 이름), 박스를 옮기거나 다시 검출하거나 프로젝트를 저장·열어도
  그대로 유지됩니다. Control 정규화와 정량은 이 레인 안의 Control 박스로 합니다. 같은 이름으로 다시 묶으면 그 레인에 박스가 더해지고,
  '직접 지정한 레인 풀기'로 위치대로 돌아갑니다.
  **병합**: 여러 박스를 선택하고 우클릭 → 병합. 한 밴드가 두 줄로 나뉘어 잡혔을 때 두 줄을 모두 선택하면 레인마다 하나로 합쳐지고, 옆 레인끼리 고르면 하나의 넓은 박스가 됩니다.
- **창 크기에 맞춤**: 왼쪽 이미지와 오른쪽 설정 창은 창 크기에 따라 비율대로 바뀌고, 이미지는 창 크기를 따라 자동으로 맞춰집니다(확대하면 그 배율 유지, '창에 맞춤'으로 복귀).
- **저장은 모두 '파일' 메뉴**: 프로젝트, 밴드 ROI·그룹, 결과 CSV, 그래프(현재 이미지 / 여러 이미지), 박스 표시 이미지, Figure 그림(⌘E).
- **배경(background noise) 제거** 4가지: 없음 / Rolling ball(이미지 전체) / 박스 위·아래 로컬 배경 / 행 내 레인 사이 배경.
- **Target / Control 지정**: 단백질마다 측정(Target), Control(Loading), 제외 중에서 고릅니다.
  Target ÷ Control을 레인별로 계산하고 기준 레인을 1로 정규화합니다.
- **수식 만들기**: *수식 추가…*를 누르면 수식 창이 열립니다. 단백질 그룹·밴드 ID·이미지별 항목·큰 그룹은 드롭다운에서 골라 *넣기*로 넣고,
  직접 입력하는 것은 `+ − × ÷ ( )`와 숫자뿐입니다(키보드나 버튼). 미리보기로 결과를 바로 확인하고, 수식을 더블클릭하면 다시 편집합니다.
  예) `pErk / Erk`, `Kras_DOX / Kras_DMSO`.
- **밴드 ROI·그룹 저장/불러오기**: 박스 위치·크기, 단백질/레인 그룹 이름과 역할만 따로 `_roi.json`으로 저장하고, 다른 이미지에 적용할 수 있습니다
  (*1. 검출* 탭 또는 *파일* 메뉴). 이미지 크기가 다르면 비율대로 맞출지 묻습니다.
- **여러 이미지 (5번 탭)**: TIF를 여러 개 열고(이미지 탭 I1, I2 …) 이미지들의 그룹을 체크해 *큰 그룹*을 만듭니다.
  - *레인 큰 그룹*: 이미지마다 이름이 다른 레인을 하나로 맞춥니다. 예) I1의 'IgG 12h'와 I2의 'IgG12'.
  - *단백질 큰 그룹*: 여러 블롯의 단백질 값을 레인별로 평균 ± SD 냅니다. 이미지마다 기준 레인을 1로 맞춘 뒤 평균합니다.
  - *이미지 간 수식*: 수식 창에서 I1·I2 …의 단백질/밴드와 큰 그룹을 골라 만듭니다. 예) `I2.Kras / I1.Kras`.
    이미지 사이의 레인은 레인 이름(또는 레인 큰 그룹)으로 맞춰집니다.
- **Control이 없으면**: Control 단백질을 지정하지 않으면 그래프와 결과에 레인별 Net intensity(raw)를 그대로 보여 줍니다.
- **그래프**: 4:3 비율로 창 너비에 맞춰 늘어납니다.
- **자동 그룹 제안**: 검출하면 단백질 그룹(P1, P2 …)과 레인 그룹(L1, L2 …)이 위치대로 자동으로 만들어집니다.
  정량이 필요 없으면 바로 Figure 탭으로 가면 되고, 고칠 때는 지금처럼 드래그로 선택 → 우클릭(새 단백질/레인 그룹)합니다.
- **Figure 만들기 (논문용 그림)**: 메인 창의 *6. Figure 만들기* 탭(⌘⇧F)에서 현재 이미지의 그림을 만듭니다. 이 탭에서는 그림 영역이 넓어집니다.
  왼쪽 = 새로 **추가**하는 도구(레인 이름·그룹 막대 층, 마커·크기 눈금, 숫자 줄), 가운데 = 미리보기, 오른쪽 = 이미 있는 것의 **속성**('선택한 대상', '그림 전체').
  미리보기에서 대상을 클릭하면 선택, **더블클릭하면 편집 모드**가 켜져 끌어서 고칩니다(Esc로 끝).
  - 단백질 그룹마다 잘라낸 패널(테두리), 왼쪽에 "IB: 단백질" 라벨, 위쪽에 레인 이름(`|`로 줄바꿈)과 상위 그룹(검은 막대 + 이름)을 그립니다.
  - 흰 배경·검은 밴드로 표시하고, 대비(흰색/검은색 기준, 감마)는 그림에만 적용됩니다. 정량값은 바뀌지 않습니다.
  - Ladder: 블롯과 같은 크기의 마커(white-light) TIF를 불러오면 *마커 참고* 탭에 블롯과 나란히 보여 줍니다.
    ladder 밴드 높이를 클릭하면 kDa 값을 입력할 수 있고, 직접 입력도 됩니다. 그림에는 마커 띠, kDa 눈금 또는 둘 다 넣을 수 있습니다.
    마커 띠의 가로 범위는 자동으로 찾고, 손으로 고칠 수도 있습니다.
  - *그림 형태*: '단백질(행)별 잘라내기'(Western 기본) 또는 '겔 전체를 한 패널로'(DNA gel 기본). 겔 전체 패널은 범위(x, y)를 숫자로 정하거나
    편집 모드에서 가장자리를 끌어 자르고, 왼쪽 라벨을 붙일 수 있습니다. 크기 눈금 단위는 kDa / bp 중에서 고릅니다.
  - *선택한 대상 편집*: 미리보기에서 글자, 단백질 패널, 마커 띠를 클릭하면 오른쪽 패널에 그 대상의 설정(내용, 글자 크기, 각도, 굵게/기울임,
    위치, 패널 여백, 층의 조건 설명·회전, 그룹 레인 범위, 마커 띠 범위·세로 보정·간격, kDa 값, 숫자 줄 형식)이 나옵니다. 왼쪽은 전체 설정입니다.
  - *레인 위 층*: 층을 몇 개든 쌓을 수 있습니다. 층마다 '레인별 이름'(예: + − + −, 12h 24h)이나 '그룹 막대'(여러 레인을 묶는 막대)를 고르고,
    회전 각도, 기울임, 그리고 층 옆 조건 설명(예: Dox, Cell number, 왼쪽/오른쪽)을 정합니다.
  - *글자 크기*: 레인 이름, 상위 그룹, 조건 설명, 단백질 이름, 마커(kDa), 정량 숫자마다 따로 정합니다. 미리보기에서 글자를 우클릭하면
    그 글자만 크기·각도를 바꿀 수 있습니다. 단백질 이름과 kDa 눈금은 블롯 왼쪽이나 오른쪽에 둘 수 있습니다.
  - 편집 모드에서는 글자를 끌어 옮기고, 마커 띠를 왼쪽으로 끌어 블롯과의 간격을 만들 수 있습니다.
  - TIF를 미리보기에 끌어다 놓으면 새 이미지로 열리고, '마커 참고' 화면에 놓으면 마커 이미지로 들어갑니다(메인 이미지 화면에도 끌어다 놓기 가능).
  - 미리보기에서 우클릭 → *패널 크기 조절 모드*: 패널 위/아래 가장자리를 끌면 그 단백질 패널의 높이가, 왼쪽/오른쪽을 끌면 모든 패널의 너비가 바뀝니다(레인 정렬 유지). 마커 띠와 kDa 눈금도 같이 따라갑니다.
  - *정량 숫자 넣기*: 정량값(Target/Control 비율, 수식 결과, 단백질 Net, 5번 탭의 여러 이미지 결과)을 골라 맨 아래·맨 위·특정 패널의 위/아래에 레인별 숫자 줄로 넣습니다.
    왼쪽 라벨, 소수점 자릿수, '기준 레인=1' 환산을 정할 수 있고, 큰 값은 공통 10의 거듭제곱(예: ×10⁷)으로 표시합니다.
  - 미리보기가 저장될 그림과 같습니다. PNG/TIFF(LZW)/PDF/SVG로 저장하고 해상도(dpi)를 고를 수 있습니다. 설정은 분석 파일(.json)에 함께 저장됩니다.
- **내보내기**: 밴드별 raw/배경/net 값, 이미지별 결과, 여러 이미지 결과를 담은 CSV. 그래프는 PNG/PDF/SVG, 박스가 표시된 이미지도 저장할 수 있습니다. 분석 파일(.json)은 다시 열어 고칠 수 있고, 예전 버전 파일도 열립니다.

## 프로젝트 저장 / 열기

*파일 → 프로젝트 저장*(⌘S), *다른 이름으로 저장*(⌘⇧S), *프로젝트 열기*(⌘⇧O, 또는 창에 끌어다 놓기).
열린 모든 이미지의 작업을 한 파일에 저장하고 한 번에 다시 엽니다.

- 저장되는 것: 블롯·마커 이미지, 검출·배경 설정, 밴드 ROI(위치·크기), 단백질/레인 그룹과 이름(→ 밴드 ID), 역할(Control/Target),
  기준 레인, 수식, 5번 탭의 큰 그룹·이미지 간 수식, 이미지별 Figure 설정 전체(층, 글자 크기, 개별 글자 조절, 패널, 마커 띠 영역·세로 보정,
  kDa, 숫자 줄, 내보내기 해상도), 그래프 옵션.
- `.blotproj`(기본): 이미지까지 들어 있는 압축 파일이라 다른 컴퓨터(Windows 포함)에서도 그대로 열립니다.
  이미지가 아주 크면(500 MB 이상) 넣을지 묻습니다. `.json`을 고르면 이미지 없이 파일 위치만 기억합니다(예전 분석 파일도 열립니다).
- 이미지가 옮겨졌으면 원래 경로 → 프로젝트 파일 기준 상대 경로 → 같은 폴더 순으로 찾고, 없으면 '파일 다시 찾기'를 묻습니다.
- 저장하지 않은 변경이 있으면 창 제목에 ● 와 '(저장 안 됨)'이 붙고, 닫을 때 저장할지 묻습니다.
- **여러 프로젝트 함께 열기**: *프로젝트 열기*에서 여러 개를 고르거나(⌘/Shift-클릭), *프로젝트 추가로 불러오기*로 지금 작업에 합칩니다.
  프로젝트 파일을 창에 끌어다 놓으면 '바꾸기 / 추가하기'를 묻습니다. 모든 이미지는 I1, I2 …로 이어서 번호가 붙고 탭에 [프로젝트 이름]이 표시됩니다.
  5번 탭에서 각 프로젝트의 측정값으로 수식을 만들 수 있습니다(예: `I1.Vinculin / I3.Vinculin`). 추가된 프로젝트의 큰 그룹·이미지 간 수식은
  새 번호에 맞춰 자동으로 고쳐집니다(이름이 겹치면 _2 등이 붙습니다). 합친 작업을 저장하면 새 프로젝트 파일로 저장합니다.

## 사용 순서

1. **1. 검출** 탭에서 TIF를 엽니다(창에 끌어다 놓아도 되고, 여러 개도 됩니다). 밴드를 자동으로 찾습니다.
2. 이미지에서 밴드를 드래그로 선택하고 우클릭해서 **단백질 그룹**과 **레인 그룹**을 만듭니다.
   박스 더블클릭: 크기 수정 / 빈 곳 더블클릭: 박스 추가 / Backspace: 삭제 / 우클릭: 그룹·병합 / 방향키: 1px 이동(Shift: 5px) / ⌘(Ctrl)+휠: 확대·축소
3. **2. 단백질 / 레인** 탭에서 역할(Target / Control)과 박스 크기를 정합니다.
4. **3. 밴드** 탭에서 밴드별 정량값과 프로파일을 확인합니다.
5. **4. 정량 / 그래프** 탭에서 현재 이미지의 기준 레인과 수식을 정합니다.
6. 이미지가 여러 개면 **5. 여러 이미지** 탭에서 큰 그룹과 이미지 간 수식을 만듭니다.

### 정량 방식

- 정량값(Net) = 박스 안 픽셀 intensity 합(integrated density) − 배경.
- Rolling ball은 이미지 전체에서 부드러운 배경을 추정해 뺍니다 (반지름은 밴드 높이의 3~5배 이상 권장).
- 로컬 배경은 박스 바로 위·아래 띠의 중앙값을, 행 배경은 같은 행에서 박스 사이(레인 사이) 픽셀의 중앙값을 픽셀당 배경으로 뺍니다.
- 가장 정확한 결과를 위해 이미저에서 내보낸 **원본 16-bit TIF**를 쓰고, 포화(saturation)된 밴드는 피하세요.
  스크린샷·JPEG는 대비 조정과 압축 때문에 값이 왜곡될 수 있습니다.

## 설치 (macOS)

### .dmg로 설치

`BlotProfiler-<버전>.dmg`를 열고 **Blot Profiler.app**을 Applications 폴더로 끌어 놓으세요.
서명되지 않은 앱이라 처음 실행 시 경고가 나오면 Finder에서 앱을 우클릭 → *열기*를 누르세요.

### 직접 빌드

```bash
git clone https://github.com/windowrainYOON/blot-profiler.git
cd blot-profiler
./build_mac.sh            # dist/BlotProfiler-<버전>.dmg 생성
./build_mac.sh --install  # 빌드 후 /Applications 에 설치까지
```

Python 3.10 이상이 필요합니다 (`PYTHON=/path/to/python3 ./build_mac.sh` 로 지정 가능).

### 소스에서 바로 실행

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python run_blot_profiler.py [이미지.tif]
```

## 개발

```bash
pip install -r requirements.txt pytest
python -m pytest tests
```

- `blot_profiler/core.py`: 이미지 로딩, 배경 제거, 밴드 검출, 정량, 수식 계산 (GUI와 독립)
- `blot_profiler/gui.py`: PySide6 GUI
- `packaging/`: PyInstaller 설정과 아이콘
- `tests/data/example_blot*.tif`: 예시 블롯 (스크린샷에서 잘라낸 저해상도 이미지, 테스트용)
