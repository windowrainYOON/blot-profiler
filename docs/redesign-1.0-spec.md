# Blot Profiler 1.0 개편 사양 (승인됨 2026-11-12)

시안 캔버스: https://claude.ai/artifact/KSQyW4Uao78mCT6dZ2BaCf (보드 1~8). 사용자가 "오케이. 개발 시작하고, 빌드까지 해줘"로 승인.
Mac에서 따로 만든 PRISM 그래프·사이드바 수식·내보내기·설정 시안도 함께 승인된 것으로 보고 이 문서와 합쳐 구현.

## 1. 전체 구조 (Apple HIG 데스크톱)
- 컨트롤 높이 28, 본문 13px, 강조색 #0066cc.
- 왼쪽 사이드바(흰색) / 가운데 캔버스(#f5f5f7) / 오른쪽 속성창(300px). 구분선 대신 명암.
- 속성은 둥근 카드(반경 11, 행 높이 40px, 행 사이 구분선).

## 2. 창 구성
- 메인 창은 두 단계만 둔다: ① 검출, ② 레인/단백질.
- 툴바에 '정량·그래프 창'과 'Figure 창' 버튼을 둔다.
- 밴드 정량, 그래프, 여러 이미지는 별도 팝업 창 하나로 통합한다. 툴바 세그먼트는 밴드 값 / 정량 / 여러 이미지.
- Figure도 별도 팝업 창.

## 3. 검출 탭
- 캔버스 위 도구 세그먼트: 선택 / 레인 선 / 단백질 선 / 마커 영역.

**파란 레인 선 (점편집 폴리라인)**
- 빈 곳 클릭: 새 선 추가.
- 선 더블클릭: 점 추가.
- 점 끌기: 선 휘기.
- ⌫: 삭제.
- 우클릭 메뉴: 점 추가 / 지우기 / 레인 선 추가 / 삭제.

**빨간 점선 단백질 선**
- 가로로 끌어 추가하고, 양끝 네모 핸들로 기울인다.
- 어느 단백질 행을 잡을지 지정한다.

**재검출 버튼**
- '레인 선 자동으로 찾기'.
- '선 기준으로 다시 검출': 사용자가 그린 레인 선과 단백질 선을 기준으로 다시 검출한다.

**검출 카드**
- 종류: Western / DNA gel 세그먼트.
- 민감도: 슬라이더 + 숫자.
- 기울기 자동 보정: 스위치.
- 회전 각도: 숫자 + 자동 스위치.

**마커 카드 (검출 탭으로 통합)**
- 마커 영역은 캔버스에서 드래그로 정한다.
- 래더 드롭다운. 기본 래더는 180,130,100,70,55,40,35,25,15,10 kDa.
- 사용자는 첫 마커 kDa만 입력한다. 위아래 밴드는 래더 순서로 자동 채우고, 칩으로 보여 주며 클릭해서 고칠 수 있다.
- 마커 위치 자동 검출 기능은 삭제한다.

## 4. 레인/단백질 탭
- 레인: 이름(글자칸)과 역할(시료/마커/제외 드롭다운)만 둔다.
- 단백질: 이름과 역할(Control/Target)만 둔다.
- 나머지 기능은 제거한다. Control 짝짓기와 측정 묶음 세트는 정량 창으로 옮긴다.
- '＋ 새 단백질' 다음에 'ROI 박스 채우기' 버튼을 둔다. 새 단백질 박스와 같은 크기의 박스를 각 레인의 같은 y 위치에 채운다.

## 5. 미리보기 캔버스 공통 (메인/정량/Figure)
- `[` 확대, `]` 축소.
- Space + 드래그: 화면 이동.
- 그냥 드래그는 ROI 수정이나 영역 선택으로 그대로 둔다.

## 6. 정량·그래프 창
- 구조는 windowrainYOON/cytosol-analysis의 cytosol/graph_window.py를 참고한다.
  - 위 70%: 그래프와 오른쪽 380px 편집기. 편집기 칩 탭은 그래프 / 데이터 시리즈 / 축 / 글꼴 / 범례·글자.
  - 아래 30%: 데이터 표. 세그먼트는 그린 값 / 밴드별 / 요약이고, 행을 고르면 메인 창에서 그 박스가 선택된다.
  - 범례와 글자 상자는 끌어서 옮기고, 더블클릭으로 편집한다.

**사이드바**
- 이미지 체크박스.
- Control 짝짓기: 기준(레인 또는 세트), Control, 1.0 기준.
- 그래프 항목 체크 목록. 자동 계산 항목과 내 수식을 함께 두고, 내 수식은 파란 글씨에 ✎·✕를 단다.
- '＋ 수식 추가'는 사이드바 안에 인라인 카드로 펼친다.
  - 이름 칸.
  - 수식 칸. 항목은 이미지와 레인(같은 레인/그룹)을 고른 뒤 단백질 칩을 눌러 넣는다.
  - 연산 버튼: + − × ÷ ( ) ⌫.
  - '1.0 기준으로 나누기'.
  - 결과값 미리보기.
  - '그래프에 추가'.

**그래프: PRISM 기본 스타일**
- 위·오른쪽 축 없음, 굵은 검정 축, 바깥 눈금, 굵은 축 이름, 격자 없음.
- 막대는 검정 테두리이고, 채움은 흰색 → 회색 → 검정 순서.
- 오차막대는 위쪽만(평균 ± SD, 캡 포함).
- 시리즈마다 점 모양을 다르게 하고, 검정 막대 위의 점은 흰색.
- 범례 테두리 없음.
- 편집기에 스타일(PRISM 기본), 색(흑백/회색/컬러), 형태(막대+점 / 점+평균선 / 막대만), SD/SEM, Y축 0부터.

## 7. Figure 창
- 툴바 세그먼트: 레인별 자르기 / Full blot.
  - Full blot은 블롯 전체를 한 장으로 보여 주고, 레인 이름·그룹 막대·kDa·단백질 이름은 그대로 붙인다.
- 왼쪽에는 추가 도구, 오른쪽에는 속성(선택한 대상 / 그림 전체).
- 더블클릭으로 편집 모드에 들어간다.

## 8. 컨트롤 규칙
- 즉시 켜기/끄기, 자동/수동: 스위치.
- 2~5개 중 하나: 세그먼트.
- 6개 이상 중 하나: 드롭다운.
- 여러 개 고르기: 체크박스.
- 연속 값: 슬라이더 + 숫자칸.
- 단위가 있는 숫자: 숫자칸 + 단위.

## 9. 내보내기
- 정량 창과 Figure 창 툴바에 '내보내기' 버튼을 둔다.
- 정량 창 메뉴:
  - 이 그래프의 데이터 CSV. 그래프에 켜진 항목·이미지·레인만 담고, 레인별 값과 그룹 평균·SD·n을 넣는다. 맨 위 # 주석 줄에 이미지, Control, 1.0 기준을 적는다.
  - 그래프 이미지 PNG/PDF/SVG.
  - 데이터 + 이미지 함께.
- Figure 창 메뉴:
  - Figure 이미지 PNG/TIFF/PDF/SVG.
  - Figure에 쓰인 데이터 CSV.
- 두 메뉴 맨 아래 '여러 개 골라서 내보내기…'.
- 파일 › 내보내기…(⌘E) 창:
  - 체크로 여러 개를 고른다.
  - 범위, dpi, 저장 위치, 파일 이름 앞부분을 정한다.
  - CSV 미리보기를 보여 준다.

## 10. 파일 › 설정…(⌘,)
- 그래프와 Figure의 기본값:
  - 글꼴과 글자 크기.
  - 축·테두리·오차막대 선 굵기.
  - 눈금 길이·방향, 점 크기, 캡 폭.
  - 형태, SD/SEM, 색, Y축 0부터.
- 프로젝트가 아니라 이 컴퓨터에 저장한다.
- '지금 열린 그림에도 적용' 버튼과 'PRISM 기본값으로 되돌리기' 버튼.

## 11. 파일 메뉴
- 모든 저장은 파일 메뉴에도 둔다.
- 메뉴 항목:
  - 새 프로젝트
  - 열기…
  - 프로젝트 추가로 불러오기…
  - 저장 / 다른 이름으로 저장…
  - ROI·그룹 저장/불러오기…
  - 내보내기…
  - 설정…
